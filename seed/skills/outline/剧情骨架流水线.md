# 剧情骨架流水线

低负担分步建大纲：先剧情与卖点，世界观后置。目标是让读者**追得清楚、越看越值**。

## 核心原则

1. 顺序：剧情种子 → 卖点 → **主轴一句话（读者追什么 + 终局方向）** → 阶段/卷目标 → **对手与压力源** → 主角贴合 → 配角 → 世界观后置 → 组装。
2. 每步几百字级，能支撑下一决策即可，不先堆设定。
3. 主轴唯一；支线必须服务主轴，禁止多主轴并列让读者不知追什么。

## 读者验收（组装前自检，勿单独交报告）

对照大纲层五问中的 1、3、5：

1. 能不能一句话说清「这本书/这卷在追什么」？
3. 往后阶段是更刺激/更大代价，还是同质循环会腻？
5. 有没有承诺打架、设定互斥等会出戏的硬伤？

## 可执行清单

1. **剧情种子（~500字）**：开局困境、核心冲突、结局方向暗示。
2. **卖点**：≤3 个，绑定主情绪与读者承诺。
3. **主轴一句话**：读者追什么 + 终局方向；开篇承诺须与此一致。
4. **阶段/卷目标**：按篇幅拆阶（长篇可映射到卷）；每阶目标/冲突/兑现/钩子。
   - **压力递升**：每阶段抬升代价、对手、信息或影响格局至少一项。
   - **中盘与不可回头**：长篇至少标出中盘局势改写点，以及无法退回日常的节点（可落在卷目标里）。
   - 禁止把同质打脸/同质误会循环当成「新阶段」。
5. **对手与压力源**：谁在挡路、压力如何连续升级；冲突不得变成纯「主角做事流水账」。
6. **主角贴合**：人设缺陷与能力如何服务剧情发动机。
7. **配角**：按主角缺口配置，不先造龙套名单；**实体入库留给人物步**，本步只做构思对齐。
8. **世界观后置**：只补约束行动的规则与舞台，禁百科；**世界节点入库留给世界步**。
9. **组装**：消矛盾，再写入卷/章节点（见《结构与卷章模板》）。

## 组装自检

- [ ] 一句话主轴（读者追什么）清晰
- [ ] 卖点≤3 且与开篇承诺一致
- [ ] 阶段目标递升，非同质循环
- [ ] 对手/压力源连续可读
- [ ] 中盘改写或不可回头点已标出（长篇）
- [ ] 主角动机驱动冲突
- [ ] 终局方向与开篇承诺不打架
- [ ] 世界观不与剧情打架

## 禁忌

- 先写万字设定再建故事。
- 多主轴并列导致读者不知追什么。
- 步骤跳步导致人设与冲突脱节。
- 单独交流水线规划稿代替卷章节点。
- 在大纲步顺带写人物/时间线/世界等实体（只写卷章节点）。
