# 黄金三章与验收

大纲「可写」的最低标准：前三章留得住读者，并打开后续大弧。正式判定由《大纲审查》/`submitOutlineReview` 负责；本 skill 只约束写入第1–3章节点时的义务。

## 核心原则

1. 不因「文档不够厚」继续扩设定；能写黄金三章即可开工。
2. 矛盾公开标出并修复，不藏雷。
3. 验收看**留人义务**是否兑现：承诺 → 加压 → 早期兑现 → 打开长线。

## 黄金三章义务（读者语言）

| 章 | 必须交付 | 读者感到 |
|----|----------|----------|
| 第1章 | 立住主角、问题、即时张力、钩子；写入 theme/conflict/majorEvents/content | 开篇承诺清晰，想继续看 |
| 第2章 | 升级矛盾，或揭示能力/约束边界 | 压力上来或规则边界可见 |
| 第3章 | 早期兑现（小翻盘/揭秘/关系进展）+ 打开下一长线问题 | 有收获，且知道后头更大 |

## 保存前检查清单

- [ ] 类型与读者预期一致
- [ ] 一句话主轴（追什么）可售
- [ ] 剧情骨架无自相矛盾
- [ ] 卖点与阶段目标对齐
- [ ] 主角/关键配角动机可读
- [ ] 世界观仅含约束行动的部分
- [ ] 第1–3章节点字段齐且可写（能支撑净变化与章末期待）
- [ ] 第3章后长线问题已打开
- [ ] 阻塞写作的待确认问题已列出

## 写入第1–3章节点时须满足

- 三章均有具体 conflict 与有序 majorEvents，content 含章末期待
- 第1章非纯日常无压力；第3章须有可感知兑现并打开下一问
- 待确认问题**仅列阻塞项**（不堆设定愿望清单）

## 禁忌

- 第1章纯日常无压力；第3章仍无任何兑现。
- 字段齐全但读感劝退（无承诺、无兑现、无长线开口）。
- 未合并输入（种子/卖点/人设等）就宣称大纲完成。
- 写作侧自行宣布正式「通过/放行」（应交审查）。
