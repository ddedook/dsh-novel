# 题材规则 · 言情

女频现言/都市情感向：安全感、主动性、情绪兑现。

## 读者期待

- 女主有代入感与主动性；情绪产品明确（被认可、珍视、尊重、看见）。
- 感情线与成长线双轴，不靠误会无限拖。
- 虐点后须反转或成长，女主不长期无力。

## 大纲重点

1. 先定女主现实困境：婚姻/职场/家庭/经济/身份/情感不平等。
2. 男主或关键异性提供冲突与情绪价值，不只身份标签。
3. 每卷女主可见成长：事业、关系主动权、真相掌控、生活选择。
4. 阻力来自现实逻辑：利益、面子、阶层、家庭、舆论。
5. 开篇承诺与主线一致：甜宠壳勿写成纯虐无补偿。

## 章纲/正文重点

- 写清女主主动选择；感情推进有行为证据（优先权、信任、主权行为）。
- 章尾优先：关系误判、真相露头、女主反击、态度转变。

## 雷点

- 女主长期受虐无成长；靠脑残误会推进。
- 男主工具人标签；爽点与读者承诺错位。
