# 大纲审查 · 言情

在通用「大纲审查」判定表与输出契约之上，按女频现言/都市情感检查。

## 题材审查重点

1. **女主困境**：婚姻/职场/家庭/经济/身份/情感不平等是否先定。
2. **双轴推进**：感情线与成长线并行；不靠脑残误会无限拖。
3. **情绪产品**：被认可、珍视、尊重、看见等承诺与主线一致。
4. **主动性**：女主有选择与反击；虐点后须反转或成长。
5. **现实阻力**：利益、面子、阶层、家庭、舆论可解释。

## 雷点

- 女主长期受虐无成长；靠误会硬拖。
- 男主工具人标签；爽点与开篇承诺错位（甜宠壳写成纯虐无补偿）。

## 判定提示

- 感情线无行为证据或女主长期无力 → `local_patch` / `rewrite_needed`
- 承诺与主线结构性错位 → `stop_for_replan`
