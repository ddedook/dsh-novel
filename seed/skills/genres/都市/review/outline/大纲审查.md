# 大纲审查 · 都市

在通用「大纲审查」判定表与输出契约之上，按都市系统流/高武异能检查。

## 题材审查重点

1. **现实压力**：钱、考试、职场、家庭、面子是否具体可见。
2. **玩法循环**：压力 → 触发 → 选择 → 兑现 → 新问题扩大。
3. **反差与评价**：低调身份 vs 超凡能力；榜单/奖金/认证/舆论可感知。
4. **能力克制**：首卷主能力宜少；限制与惩罚齐全。
5. **地图递进**：社区/学校 → 组织/城市 → 全国或超凡隐秘层。

## 雷点

- 系统说明书灌水；无现实压力的爽点空转。
- 反派现代傻子；全程装逼无评价变化。

## 判定提示

- 缺现实压力或循环断裂 → `local_patch` / `rewrite_needed`
- 玩法与读者承诺错位 → `stop_for_replan`
