# 题材规则 · 都市

覆盖都市系统流与都市高武/异能：现代舞台 + 可量化爽点。

## 读者期待

- 现实压力具体（钱、考试、职场、家庭、面子）；金手指/异能解决压力并引来更大压力。
- 反差：低调身份 vs 超凡能力；公开评价（榜单、奖金、认证、舆论）可感知。
- 日常与超凡交替，不能只有打架或只有签到。

## 大纲重点

1. 先定核心玩法：系统触发/异能边界 + 限制惩罚。
2. 循环：压力 → 触发 → 选择 → 兑现 → 新问题扩大。
3. 首卷主能力宜少（约 1 主 + 1 辅）；微创新≤3。
4. 建现代评价体系：学校/公司/武馆/官方/平台榜单。
5. 地图：社区/学校 → 组织/城市 → 全国或超凡隐秘层。

## 章纲/正文重点

- 写清现实压力与能力触发点；奖励须改处境，不只堆数据。
- 认知差：旁人觉不可思议，主角有代价。
- 章尾优先：新任务、副作用、榜单、身份暴露、更强对手。

## 雷点

- 系统说明书灌水；无现实压力的爽点空转。
- 反派现代傻子；全程装逼无评价变化。

## 联动区块

level · overview（卖点）· role（身份反差）
