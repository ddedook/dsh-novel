# 大纲审查 · 玄幻

在通用「大纲审查」判定表与输出契约之上，按男频玄幻/升级幻想检查。

## 题材审查重点

1. **主轴唯一**：复仇/登顶/救人/破局/改命择一为主，支线服务主轴。
2. **四层压力**：同辈 → 家族/宗门 → 地图势力 → 天道/世界规则，是否逐步展开。
3. **升级路径**：阶段递升须抬升资源、敌人、认知或影响范围至少一项；忌机械刷数。
4. **金手指边界**：触发、消耗、冷却、暴露、反制是否写清。
5. **换地图收束**：换地图带走旧伏笔/旧敌/旧情感至少一项。

## 雷点（命中则倾向 patch / structural）

- 无代价全能金手指。
- 同质打脸循环无新目标。
- 设定百科先于故事；换地图不收束旧冲突。

## 判定提示

- 缺升级路径或压力层断裂 → `rewrite_needed` / `local_patch`
- 主轴混乱或金手指无限制导致故事不可控 → `stop_for_replan`
