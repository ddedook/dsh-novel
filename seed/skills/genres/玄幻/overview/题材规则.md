# 题材规则 · 玄幻

男频玄幻/升级幻想向。先定读者承诺，再约束大纲与正文。

## 读者期待

- 低位压迫 → 崛起；力量体系清晰可追踪。
- 爽点：突破、越级、打脸、夺宝、换地图、更高层压迫。
- 每阶段有新目标，升级不是机械刷数。

## 大纲重点

1. 主线只定一个主轴（复仇/登顶/救人/破局/改命）。
2. 四层压力：同辈 → 家族/宗门 → 地图势力 → 天道/世界规则。
3. 金手指有限制：触发、消耗、冷却、暴露、反制。
4. 地图逐级展开；换地图带走旧伏笔/旧敌/旧情感至少一项。
5. 阶段递升：资源、敌人、认知、影响范围至少升一项。

## 章纲/正文重点

- 章目标常为：突破、夺宝、试炼、打脸、追杀、拜师、换地图、揭规则。
- 战斗有策略、代价、误判、底牌，忌纯数值碾压。
- 章尾优先：更强敌、规则反噬、身份暴露、资源争夺升级。

## 雷点

- 无代价全能金手指；同质打脸循环。
- 设定百科先于故事；换地图不收束旧冲突。

## 联动区块

level（能力与代价/成长）· world（规则/势力地图）· outline（阶段目标）
