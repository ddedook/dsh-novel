# 大纲审查 · 历史

在通用「大纲审查」判定表与输出契约之上，按历史/架空/年代检查。

## 题材审查重点

1. **时代压力**：制度、身份、资源、战争、舆论、家族是否可见。
2. **信息差落地**：主角优势（信息/技术/组织/商业/军事）如何赢，须可执行。
3. **对手有资源**：反派具备时代制度与资源优势，非现代傻子。
4. **公开评价逆转**：每卷至少一次考中/立功/破案/赚钱/翻案等可感知逆转。
5. **考据服务冲突**：细节只保留与冲突相关者，忌展览式旁白。

## 雷点

- 考据展览；穿越无代价无对手。
- 古人无脑捧杀；时代感仅靠服饰名词。

## 判定提示

- 缺时代压力或信息差无法落地 → `local_patch` / `rewrite_needed`
- 历史外壳与读者承诺错位（写成纯玄幻升级）→ `stop_for_replan`
