# 题材规则 · 末世

末世丧尸/进化/基地向：感染规则与物资约束下的生存、建基与人性博弈。

## 读者期待

- 每阶段有生存压力与可执行目标：搜刮、建基、尸潮、撤离或追查源头。
- 压力来自感染、尸潮、口粮弹药、基地秩序、信任与人性裂痕。
- 长篇有主线或终极真相（病毒源头、进化阶跃、安全区谎言）串联各阶段。

## 大纲重点

1. 先定主线机制：爆发起因、感染规则、异能/晶核边界、基地准入逻辑。
2. 每卷一个生存阶段，卷内目标一句话可说清（立足、守潮、迁徙、远征）。
3. 资源约束、死亡条件、黑市交易、错误求生线齐全。
4. 小队/基地按职能配置，含背叛与内斗风险。
5. 卷末回收阶段真相，扩大世界问题（进化尸、军阀、科研黑幕）。

## 章纲/正文重点

- 推进生存压力或建基目标，忌纯聊天。
- 写明资源变化：弹药、食物、晶核、伤势、理智、信任。
- 设定服务选择，不做说明书。
- 章尾优先：尸潮临近、配给变更、队友异常、感染暴露、真相反转。

## 雷点

- 设定讲座无选择；无限开挂无视资源与感染规则。
- 各卷互不关联、无主线回收；写成星际舰队或修仙境界主叙事。
