# 大纲审查 · 末世

在通用「大纲审查」判定表与输出契约之上，按丧尸/进化/基地向检查。

## 题材审查重点

1. **主线机制**：爆发起因、感染规则、异能/晶核边界、基地准入逻辑是否先定。
2. **生存阶段**：每卷一个可说清的生存目标（立足、守潮、迁徙、远征）。
3. **资源约束**：口粮弹药、伤势理智、信任与死亡条件齐全。
4. **人性裂痕**：小队/基地含背叛与内斗风险。
5. **卷末扩大问题**：进化尸、军阀、科研黑幕等回收并抬升。

## 雷点

- 设定讲座无选择；无限开挂无视资源与感染。
- 各卷互不关联、无主线回收。

## 判定提示

- 缺感染/资源规则或阶段目标不清 → `rewrite_needed`
- 写成星际舰队/修仙境界主叙事偏离末世承诺 → `stop_for_replan`
