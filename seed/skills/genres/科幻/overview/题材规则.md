# 题材规则 · 科幻

科幻/末世/任务制世界：规则与资源约束下的选择与生存。

## 读者期待

- 每阶段/副本有独立目标与规则；靠信息、准备、团队、资源管理活下去。
- 压力来自时间、物资、规则、敌人与信任。
- 长篇有主线或终极真相串联各阶段。

## 大纲重点

1. 先定主线机制：灾变成因、科技/异常边界、任务发布逻辑。
2. 每卷一个阶段，卷内目标一句话可说清。
3. 资源约束、死亡条件、隐藏奖励、错误通关线齐全。
4. 团队按功能配置，含背叛风险。
5. 卷末回收阶段真相，扩大世界问题。

## 章纲/正文重点

- 推进任务或生存压力，忌纯聊天。
- 写明资源变化：弹药、食物、时间、权限、信任、伤势。
- 设定服务选择，不做说明书。
- 章尾优先：倒计时、任务变更、队友异常、资源失效、真相反转。

## 雷点

- 设定讲座无选择；无限开挂无视资源。
- 副本互不关联、无主线回收。
