# 大纲审查 · 科幻

在通用「大纲审查」判定表与输出契约之上，按科幻/任务制世界检查。

## 题材审查重点

1. **主线机制**：灾变成因、科技/异常边界、任务发布逻辑是否先定。
2. **阶段目标**：每卷目标一句话可说清；资源与死亡条件齐全。
3. **技术自洽**：设定服务选择，不百科灌水；能力有边界。
4. **尺度推进**：阶段间问题扩大（权限、敌我、真相层级）。
5. **团队风险**：按职能配置并含背叛/误判风险。

## 雷点

- 设定讲座无选择；无限开挂无视资源。
- 副本互不关联、无主线回收。

## 判定提示

- 技术设定自相矛盾或阶段无目标 → `local_patch` / `rewrite_needed`
- 无主线机制串联 → `stop_for_replan`
