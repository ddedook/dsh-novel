# 大纲审查 · 悬疑

在通用「大纲审查」判定表与输出契约之上，按规则怪谈/悬疑调查检查。

## 题材审查重点

1. **规则三层**：表层规则 → 隐藏例外 → 真相规则是否可回溯。
2. **线索公平**：误导 → 验证 → 反证 → 汇聚 → 揭示；读者应能推理，忌作者开上帝视角硬补规则。
3. **惩罚可回溯**：死亡/代价须有逻辑，忌纯随机吓人。
4. **能力边界**：能力只助观察/试错，不能无视规则通关。
5. **卷末回收**：核心规则回收并打开更高层问题。

## 雷点

- 无逻辑惊吓；结局靠新规则硬翻盘。
- 线索不对读者公平；有能力直接跳过谜题。

## 判定提示

- 规则自相矛盾或线索链断裂 → `rewrite_needed` / `stop_for_replan`
- 单案缺通关线/死亡线 → `local_patch`
