# 题材规则 · 悬疑

规则怪谈/悬疑调查：规则自洽，推理可回溯，恐惧与反制并存。

## 读者期待

- 规则看似荒谬但背后有逻辑；观察、试探、代价、推理破解。
- 恐惧来自「不知哪条为真」；爽点来自「看懂后反制」。
- 每案/副本有背景、通关线、死亡线、隐藏真相。

## 大纲重点

1. 三层规则：表层 → 隐藏例外 → 真相规则。
2. 惩罚可回溯，忌纯随机吓人。
3. 线索：误导 → 验证 → 反证 → 汇聚 → 揭示。
4. 能力只助观察/试错，不能无视规则。
5. 卷末回收核心规则，打开更高层问题。

## 章纲/正文重点

- 至少推进一条规则验证或反证。
- 场景序：异常 → 触边界 → 代价 → 线索 → 调整判断。
- 记录伏笔：规则文本、异常行为、受害者差异、场景细节。
- 章尾优先：规则冲突、同伴违规、安全规则被推翻。

## 雷点

- 无逻辑惊吓；结局靠作者开上帝视角新规则。
- 线索不公平（读者无法推理）；有能力直接跳过谜题。
