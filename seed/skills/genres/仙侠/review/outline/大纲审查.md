# 大纲审查 · 仙侠

在通用「大纲审查」判定表与输出契约之上，按修仙/仙侠检查。

## 题材审查重点

1. **境界质变**：境界差异须有质变，不只改称号。
2. **机缘代价**：因果、心魔、天妒、宗门争夺须落地。
3. **势力张力**：宗门/散修/魔道（或等价三角）可用。
4. **渡劫节点**：每卷至少一个渡劫或近死破境节点。
5. **仙凡交织**：人情债与天道冷规则并存；长线指向更高天域但不透支终局。

## 雷点

- 境界灌水无质变；无心性的纯数值仙。
- 全程打怪升级，无因果与人情。

## 判定提示

- 境界无质变或机缘无代价 → `local_patch` / `rewrite_needed`
- 修仙叙事被纯玄幻打脸循环替换且无心性线 → `stop_for_replan`
