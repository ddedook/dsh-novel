# 题材规则 · 仙侠

偏修仙/仙侠：道与劫、宗门天梯、飞升长线。与玄幻升级流共享骨架，强调「修」的代价与境界质变。

## 读者期待

- 从凡到仙的阶梯感；心性、机缘、天劫同样重要。
- 爽点：破境、渡劫、悟道、夺宝、名震一方、飞升在望。
- 仙凡对照：人情债与天道冷规则交织。

## 大纲重点

1. 境界体系写清质变差异（不只改称号）。
2. 机缘有代价：因果、心魔、天妒、宗门争夺。
3. 宗门/散修/魔道三角张力，内部派系可用。
4. 每卷至少一个「渡劫或近死破境」节点。
5. 长线指向更高天域/飞升，但不透支终局。

## 章纲/正文重点

- 修炼戏要有风险与选择，忌闭关旁白涨战力。
- 法宝/功法有使用史与暴露风险。
- 章尾优先：心魔、天劫征兆、宗门追杀令、上界注视。

## 雷点

- 境界灌水无质变；无心性的纯数值仙。
- 全程打怪升级，无因果与人情。

## 联动区块

level · world（规则/势力）· role（心性缺陷）
