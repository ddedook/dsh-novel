# 生物档案要素

除人物外的生物（动物、异兽、通灵植物、灵体等）写入时注意。读者向：出场有辨识与代价，归属不乱。

## 写库要点

1. **种类 `kind`**：库表标量 `animal|beast|plant|spirit|other`，不要塞进 profile。
2. **名称唯一**：全书生物名唯一；别名可写在档案字段。
3. **主人可选**：有主则 **`owner` 传人物名字符串**（勿传 UUID / 勿用 `ownerId`）；野生/无主省略或置空。
4. **档案写满**：栖息、习性、能力、外形、危险等级、来历等按模板 key 覆盖大半，避免只剩名字。
5. **时间线**：驯养、觉醒、战损、易主等关键节点写进 `creatureTimeline`（须 `creatureId|creatureName` + `timeLabel` + 整数 `timePoint` + 非空 `content`；有标题则写 `title`）。

写作时突出辨识特征与战力代价，勿与人物档案混写。有主人时先确保人物已存在。
