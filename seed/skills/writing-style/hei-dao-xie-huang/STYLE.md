## I — 文风骨架 (Interpretation)

用**第三人称冷硬旁白**：镜头跟主角行动与压迫感走，极少上帝式抒情。情绪靠动作、目光、短对话落地，不靠形容词堆砌。

语域是**都市黑道白话**：规矩、招降、归顺、据点、帮众、见面礼；狠话短、威胁冷。脏话可用，但要服务场面，不当油腻段子连续轰炸。

节奏：**短句加压 → 拟声落地（哗/啪/嘭/砰/咣当）→ 结果写清 → 众人反应/臣服**。场面切镜硬切，少温吞过渡。打斗写「速度、力度、残影、骨裂、血柱」与围观者变色，不写招式说明书。

对话：出口即规矩或试探；主角常「不想惹事 / 别惹我 / 明白，鹰哥」式短句。群像用怪笑、冷哼、憨笑、互怼推关系，基调仍是**狠与秩序**，不是社死喜剧。

爽点结构：被人看轻/围困 → 冷警告 → 爆发碾压 → 全场死寂或目光变色 → 立规矩/收归顺。余韵写臣服与权柄，不写长篇自我感动。

设定：势力、据点、任务期限短插即可，挂在当场决策上；禁止百科墙。

## A1 — 源作中的落地 (Past Application)

### 案例 1: 夜场渗入与血杀

- **情境**: 少年持刀问铁头房间，下药送酒
- **手法**: 感官冷硬（刀锋/血槽）→ 短问短答 → 假身份对话推进 → 包间糜烂对照
- **效果**: 开篇即立「狠、冷、少废话」声口

### 案例 2: 牢房立威

- **情境**: 山猫喷痰、动武、羞辱床铺
- **手法**: 主角两次「别惹我」冷警告 → 挨打不跪 → 森寒目光压场 → 反击在蓄势后爆发
- **效果**: 规矩与压迫感先于武力展示

### 案例 3: 归顺与灭口

- **情境**: 许琨跪雪归顺，随即清狼群
- **手法**: 握手欢迎 → 职务一句定 → 枪声硬切 → 血柱与雪夜对比
- **效果**: 黑道问鼎逻辑：收可用之人，清隐患不留温情戏

## E — 可执行步骤 (Execution)

1. **定通道** — 第三人称跟当前狠人 POV；少跳全知抒情。完成标准：段落能回答「谁在行动/施压」。
2. **定压迫与规矩** — 本场要有试探、羞辱、围困、招降或死线之一。完成标准：场末留下威慑或未解冲突。
3. **先感官/动作后解释** — 刀、血、拟声、脚步先落地。完成标准：开头 3 句内有可感知细节。
4. **对话短冷** — 威胁、命令、归顺用语优先；长篇自白砍掉。完成标准：关键对白不超过两三句堆叠说教。
5. **爽点三拍** — 看轻/蓄势 → 短爆发（拟声+结果）→ 死寂/臣服/立规矩。完成标准：爆发段少空形容词。
6. **群像服务权柄** — 互嘲、憨笑可有，但最终落回老大目光与号令。完成标准：不写成纯搞笑番外。
7. **过禁忌清单** — 对照 B 段。完成标准：无 AI 空抒情、无百科墙、无温吞和解冲淡立威。

## B — 边界 (Boundary)

### 不要在以下情况强行套用

- 需要细腻心理文学腔、纯甜宠慢热
- 需要密集现代吐槽/游戏梗的轻喜剧（那是大奉风）
- 纯推理冷静报告、严肃纪实

### 失败模式

- 「他深邃地望着命运的齿轮」——空，不像
- 通篇脏话段子、无规矩推进——油腻
- 打斗写成武术教材或战力表——拖死节奏
- 招降写成演讲感动大会——丢黑道气场
- 每场都无脑碾压独白——缺蓄势与围观变色

### 容易混淆

- 与一般「无敌爽文」：邪皇风爽点仍要有冷警告、规矩与臣服余韵
- 与纯暴力猎奇：暴力服务权柄与秩序，不为主角无目的虐杀展览
