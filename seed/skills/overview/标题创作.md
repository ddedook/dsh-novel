# 标题创作

标题是第一印象；选定后写入本书 **书名**（`novels.title`）。按题材风格生成候选，用不同技巧拉开差异。

## 核心原则

1. 先定题材，再匹配风格；跨题材时优先核心冲突对应风格。
2. 每个候选使用不同起名技巧。
3. 一眼可感故事方向，又留一点好奇。

## 题材-风格映射

| 题材 | 风格 | 常用结构 |
|------|------|----------|
| 悬疑/推理 | 悬念 | 谜、局、消失的X、第N个X |
| 言情/甜宠 | 诗意/温暖 | 意象、四字、对比 |
| 玄幻/奇幻/仙侠 | 宏大/古风 | 录、传、纪、诀、歌 |
| 科幻 | 未来/哲思 | 技术意象、悖论 |
| 历史 | 厚重/时代 | 年代、地名、事件锚点 |
| 都市/现实 | 生活化 | 口语、反差 |
| 末世 | 压迫/求生 | 废土、生存、秩序 |

（产品分类常见：玄幻、仙侠、都市、历史、科幻、悬疑、言情、末世等；以本书 `category`/概述 `genre` 为准。）

## 五种起名法

1. **冲突提炼**：关键词直指核心矛盾。
2. **主角命名**：突出最独特身份/处境，避免全名传记感。
3. **意象隐喻**：象征主题，可读中回味。
4. **反差并置**：矛盾元素制造「为什么」。
5. **悬念留白**：不说破真相，留下缺口。

## 输出与落库

- 输出 3–5 个候选，标注所用技巧与题材风格。
- 每个候选附一句：为何适合本书主情绪/卖点。
- 用户选定后更新书名；可与概述 `theme`/`coreConflict` 一致，勿只改聊天不改书名。

## 禁忌

- 五个标题同一种结构或同义词堆砌。
- 剧透终局、空泛大词（命运、传说、永恒）无具体锚点。
- 与核心冲突/主角处境无关。
