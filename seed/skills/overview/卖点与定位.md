# 卖点与定位

把灵感压成可约束全书的定位，并写入概述 blueprint。读者向：十秒知「追什么/什么爽」。

## 核心原则

1. 一句话确认读者承诺：读者打开这本书最想看什么。
2. 核心卖点最多 3 个；超过则合并或降级。
3. 主情绪不可偏移；大纲、人物、正文都必须服务它。
4. 差异化服务追读与爽点，不为复杂而复杂。

## 可执行清单

1. 拆灵感：题材 / 人物 / 冲突 / 爽点或虐点 / 反转 / 世界观元素。
2. 定目标读者与主幻想（变强、翻盘、关系独占、揭秘等，只选一个主轴）。
3. 写清表层卖点、深层爽点、长线钩子。
4. 检查长线：能否拆出 ≥5 个不重复剧情方向。
5. 写清首卷卖点与前三章必须兑现的承诺。
6. 列出风险与避坑（题材偏移、期待断裂、设定崩坏、情绪不兑现）。

## 写入概述 blueprint（键名对齐产品）

落库/更新概述时优先填这些键（模板包含则写入；勿另起平行标签当唯一真相）：

| 定位内容 | blueprint 键 |
|----------|----------------|
| 题材标签（可多选） | `genre` |
| 主情绪 / 调性 | `tone` |
| 核心冲突 | `coreConflict` |
| 驱动力 / 动机 | `motivation` |
| 主题 | `theme` |
| 目标读者 | `targetAudience` |
| 文风参考 | `styleReference` |
| 叙事视角 / 人称 | `narrativePerspective` / `narrativePerson` |
| 章数规划 | `chapterCountPlan` |
| 单章目标字数 | `chapterWordTarget` |
| 其他硬约束 | `specialRequirements` |

一句话核心梗与开篇承诺可写入 `coreConflict`/`specialRequirements` 或 theme 旁注，须能被后续大纲检索。

## 写入自检

- 读者十秒能感到追什么、主情绪是什么
- 卖点≤3 且与 `tone`/`coreConflict` 一致
- 前三章承诺可检验

## 禁忌

- 只写市场标签，不写读者承诺与主情绪。
- 卖点超过 3 个且互不咬合。
- 首章无危机/杠杆，前三章无第一次有效回报。
- 定位只停在聊天，不写概述 blueprint。
