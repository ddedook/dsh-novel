# 开书种子

用户没有明确想法时，生成可追读的网文向开书方向；有想法时改为补全最小输入。读者向：十秒可售、前三章能留人。

## 核心原则

1. 目标是可卖、可代入、前三章能兑现，而非文学概念展示。
2. 每条种子必须含：主角处境 + 开局困境 + 核心杠杆 + 主动选择 + 首章爆点 + 长篇升级暗示。
3. 成熟赛道 + 一个改变推进方式的新变量。
4. **选中或确认方向后，必须落到概述 blueprint**（见《卖点与定位》）；设定写完即停，等用户 `/novel-outline`。勿停在聊天灵感。

## 最小输入（有想法时）

先确认或追问：

1. **题材**：赛道与主情绪 → `genre` / `tone`
2. **主角**：身份/缺陷/想要什么 → 驱动 `motivation`，并后续建 role
3. **核心冲突**：外部压力与驱动力 → `coreConflict`

不够则补问，够则写入概述并完成定位；不要进入大纲，等用户 `/novel-outline`。

## 五条种子功能位（无想法时）

各保留一条，功能实质不同：

1. **强钩子**：极端处境 + 可反击杠杆。
2. **人物成长**：弱到强/低位到高位路径清晰。
3. **设定奇观**：规则变成可争夺、可升级资源。
4. **关系牵引**：情绪回报 + 立场/秘密冲突。
5. **悬念追查**：谜团绑定力量/身份/生存，分层揭开。

## 内部筛选门槛（不向用户展示过程）

- 十秒可售：题材 + 处境 + 杠杆 + 主回报。
- 首章有危机、主动选择、杠杆亮相。
- 前三章能第一次翻盘/揭秘/关系进展。
- ≥三档量级不同的目标/对手/地图。
- 五条在幻想与爽点结构上实质不同。

## 确认后路径

1. 用户选定/混合一条种子（或提供自己的想法）
2. 写入概述 blueprint：`genre`、`tone`、`coreConflict`、`motivation`、`theme`、`targetAudience` 等
3. 设定写完即停，等用户调用 `/novel-outline`；勿在开书步骤写卷章节点。

## 输出契约（无想法时）

```markdown
1. 【强钩子】一句话种子
2. 【人物成长】…
（共 5 条）
请选择一条、修改、混合，或提供自己的想法。选定后将写入概述。
```

## 禁忌

- 电影梗概、单次反转、纯设定展示。
- 五条都是「获能力—解危机—发现阴谋」换皮。
- 抽象大词代替具体画面与行动。
- 选定后不写概述，直接空转聊天。
