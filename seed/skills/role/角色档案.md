# 角色档案

角色不是散文小传，而是后续大纲与正文可读的状态卡。读者向：闭眼能辨声口；关系变化可读。

## 核心原则

1. 每个重要角色有**动机三角**：想要 / 害怕 / 信念。
2. 区分故事功能与情绪功能；重大选择须能追溯到动机三角。
3. 缺信息标「待补充」，不编造成已确认事实。
4. 深度分级：锚点（一句话）→ 完整档案 → 章节当下状态。

## 写库契约

- **只建重要角色**：主角/核心配角及后续大纲、正文会复用者入库；路人、一次性龙套不必建档（正文临场描写即可）。
- **`name`**：全书人物名；创建/更新人物实体。
- **`faction`**：归属势力/聚居点名，须**等于**已有世界节点名（优先 `faction` 等组织类；无势力时可用 `city`/`town`/`settlement`）；勿自造未建档名称。**有势力归属时先保证 world 节点存在**（开书创建同此）。
- **模板字段写顶层**：先 `get_template`，按 `role.detailFields` 的 key 写在实体根上（如 `occupation`、`roleType`），**不要**包进 `profile`。
- **关系**：多人互动用 `roleRelation`（`from`/`to` 姓名或 `roleId`/`targetRoleId` + `relationType` + `content`），不要只写在档案散文里。系统按姓名解析；内容页两侧都能看到同一条有向边，不要再插一条反向行。
- **履历**：晋升、负伤、重大抉择须同步写 `roleTimeline`（`roleId`/`name` + `timeLabel` + 整数 `timePoint` + `content`）；装饰性时间点不必入库。开书建档若已有重要履历，一并写入，勿只塞档案散文。

## 可执行清单

### 动机三角

- 想要：当前具体目标（可检验）。
- 害怕：最怕失去什么。
- 信念：他以为世界/自己/他人如何。

### 主角必填差

- 显性/隐性身份、金手指边界、核心弱点、成长状态。

### 反派必填差

- 独立目标、资源层级、压迫手段、失败节点、是否可洗白。

### 语言风格卡（重要角色）

- 用词习惯、句长、口头禅、禁忌话题、对谁说话会变。

## 写入自检

- 动机三角可追溯到后续选择
- `faction` 已对齐世界节点（若有归属）
- 关键关系已有 `roleRelation` 边，而非仅散文一句

## 禁忌

- 只有外貌与履历，无动机三角。
- 金手指无限制、无代价、无暴露风险。
- 用空话（命运之子、神秘强大）代替可执行设定。
- `faction` 填不存在的世界节点名。
