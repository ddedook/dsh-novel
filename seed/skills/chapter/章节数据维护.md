# 章节数据维护

正文落库用 `mutate_entities`（domain=`chapter`）。身份只要 `ordinal`（章号）+ `name`（短名，如 `灭门夜`）；界面显示「第1章 灭门夜」，**不要**把「第1章」写进 `name`。`chapterNo` 仅作 `ordinal` 的兼容别名。`content` 是正文。可选 `relatedOutlineId` 或 `relatedOutlineName` 挂到大纲章节点。

写章时除正文外，必须用 `mutate_entities` 同步本章引起的设定变更。目的：防止下一章读者出戏（人突然没了、神器归属错、生物首次出场无档）。

## 必须同步的设定变化

| 类型 | domain | 示例 |
|------|--------|------|
| 新出场人物 / 人物档案变化 | `role` | 新配角、主角受伤后状态更新 |
| 关系变化 | `roleRelation` | 结盟、决裂、师徒（一条有向边即可） |
| 人物履历 | `roleTimeline` | 晋升、负伤、重大抉择 |
| 物品流转 | `item` | 获得神器、损毁、转手 |
| 物品履历 | `itemTimeline` | 认主、封印、损毁 |
| 新出场生物 / 生物档案变化 | `creature` | 新异兽、灵植状态变化 |
| 生物履历 | `creatureTimeline` | 驯化、反噬、死亡 |
| 世界节点 | `world` | 新地点、势力易主 |
| 世界线 | `worldTimeline` | 某地战乱、政权更迭 |
| 主时间线 | `timeline` | 冲突、悬念、伏笔、转折 |
| 等级体系 | `level` | 体系/等级规则变化（较少见） |

## 可声明无变更

若本章仅推进剧情、不改动任何设定档案，不必 mutate 其它域。

## owner 与宿主（易混）

- `item` / `creature` 的 `owner` = 归属主人的**人物名字符串**。
- 附属时间线宿主用 `roleName` / `itemName` / `creatureName`（或对应 `*Id`），不是 owner 字段。
- 主人变更 = 实体 `owner` + 对应 `*Timeline`，缺一不可。

## 各域 payload 必填

| domain | 写入 |
|--------|------|
| `chapter` | `ordinal` + `name`；正文放 `content` |
| `role` / `item` / `creature` | `name` + 模板字段顶层 key |
| `roleRelation` | 双方引用（from/to id 或 name）+ `relationType` + 非空 `content` |
| `roleTimeline` | `roleId`\|`roleName` + `timeLabel` + `timePoint` + 非空 `content` |
| `itemTimeline` | `itemId`\|`itemName` + `timeLabel` + `timePoint` + `content` |
| `creatureTimeline` | `creatureId`\|`creatureName` + `timeLabel` + `timePoint` + `content` |
| `worldTimeline` | `worldNodeId`\|`worldNodeName` + `timeLabel` + `timePoint` + `content` |
| `timeline` | `timeLabel` + `timePoint` + `title` + `content` + `eventType` |
| `world` | `name` + `kind` |
| `level` | `system.name` + 非空 `system.levels` |

## 流程

1. `query_entities` / `get_entities` 读对应大纲章合同与相关设定
2. 写正文
3. `mutate_entities` 写入 `chapter`（`ordinal` + `name` + `content`）
4. 本章改动的设定同样用 `mutate_entities` 写入对应域

## 禁忌

- 正文出现新人物名却不写入 `role`
- 正文出现新生物名却不写入 `creature`
- 只写正文不同步设定变更
- 用空 query 拉全书索引浪费上下文（应带名称查询）
- 把「第N章」写进 `name`
