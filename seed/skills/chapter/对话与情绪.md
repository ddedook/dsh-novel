# 对话与情绪

对话揭示人物、推动情节、制造冲突；情绪曲线服务章目标。对白排版与口吻直接决定读者是否出戏。

## 核心原则

1. 每句对话至少服务：推情节 / 揭人物 / 造冲突 / 传信息 / 表情感 / 造悬念。
2. 简洁；真实对话可打断、迟疑、话未说完。
3. 不同身份风险偏好与用词不同；闭眼听对白应能分辨说话人，三人同腔 = 失败。

## 对白标点（硬约束）

- 人物说出的话一律用中文弯引号：`“……”`
- **禁止**：英文直引号 `""`、直角引号「」、圆括号 `()`、方括号 `[]`、书名号 `《》`、`『』` 等充当对白外壳
- 标签习惯：`道：“……”` 或 `“……”某某道`；多用动作/神态代替连续「他说/她道」
- 内心独白：不入引号，用叙述或斜切内心；**禁止**括号夹注（如`（他心想……）`）
- 省略、打断用 `……` / 话未说完截断；不以 `...` 或破折号堆砌替代引号

## 可执行清单

### 对话

- 删寒暄与无信息问答。
- 潜台词：表面说 A，实际争 B（对白是给对方听的版本）。
- 冲突对话：目标对立，各不让步或假意让步。
- 设定用行动/冲突带出，禁止说明书腔大段讲设定。

### 视角与信息差

- 单场戏默认跟一个 POV，禁止无标跳头（读者会懵）。
- 读者信息与角色信息不强行对齐；用信息差推冲突。

### 情绪曲线

- 定本章主情绪与起伏点（加压→误判→爆发→余波）。
- 情绪落在身体反应、物件、他人反应上，少用抽象词。
- 虐点后有补偿或新目标，避免纯虐空转。
- 每章至少一个可读回报（关系/信息/局势），与节奏 skill 一致。

## 修订自检（改对话时内心核对，勿单独交报告）

- 无效句是否已删或改成有目的的版本
- 关系/信息是否因对话产生净变化
- 三人说话是否像同一个人
- 对白外壳是否全部为 “”

## 禁忌

- 「你好」「吃了吗」式无效对话。
- 用对话大段讲设定（说明书腔）。
- 格言化旁白替代人物当场反应。
- 非 “” 对白外壳或括号夹注对白/内心。
