# 去AI味与质检

提升场景感与人物差异；按读者读感修文。正式判定（`accepted` 等）由审查 skill / `submitChapterReview` 负责；写作侧只做自检与修订。

## 核心原则

1. 保留：已发生事实、人物硬设定、信息边界、伏笔、物件归属、时间序、章末牵引。
2. 不为「像人」而加错别字、病句、隐形字符或伪造经历。
3. 同类问题连续出现再修；单次可不处理（成簇才修）。

## 审计对象（读者症状 → 诊断；成簇才修）

- 「读着像作文/假」← 否定式并列过密（「不是X，而是Y」）、格言化旁白（「权力是…」「命运从不…」）、解释性推进（叙述者替读者下结论）
- 「全员一个腔」← 人物口吻均质；段落模板过齐
- 「场面摸不着」← 抽象感官词替代可触摸细节；悬空判断（「局势复杂」无场景落点）
- 「段段总结收束」← 万能转折词堆砌、每段末口号式收束

## 二稿顺序

1. 列出不可改事件与信息边界。
2. 挑 3–8 处表达簇场景化改写（物件/停顿/误说/他人反应）。
3. 重写成连续正文，勿保留初稿句序骨架。
4. 按章节合同与读者验收五问复验（见《章节节奏与开头》）。

## 修复顺序

保留必兑爽点与事实 → 最小片段替换 → 无效再整章 → 复验合同与五问 → 仍有小问题则记质量债并停止死循环（勿与审查判定死磕）。

## 禁忌

- 以外部「AI检测分」为唯一目标反复重写。
- 修文时改掉必须事件或章末钩子。
- 全词表机械替换制造假「人味」。
- 写作侧自行宣布 `accepted` / 正式放行。
