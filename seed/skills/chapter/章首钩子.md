# 章首钩子

章尾逼读、制造翻页欲；钩子强度与信息边界匹配。开头类型与章骨架见《章节节奏与开头》。

## 核心原则

1. 每章结尾必须有有效钩子（危机、揭示、未完成动作、两难等）。
2. **验收主句：翻页欲**——钩子须改写读者对局势的理解或下一步期待。
3. 假钩子伤害信任，比弱钩更糟。

## 章首（交叉引用）

开头手段（行动切入 / 反常画面 / 危险对话 / 倒计时 / 发现物证等）见《章节节奏与开头》。引子后迅速进入本章目标，不长时间空转。

## 章尾钩子（常用）

1. **突然揭示**：信息改写现状。
2. **紧急危机**：下一章必须应对。
3. **未完成动作**：打断在结果前。
4. **身份反转**：关系重定义。
5. **两难选择**：决定前截断。
6. **新压力源**：更强敌/规则反噬/资源争夺。

## 悬念强度

- 弱：好奇细节 → 中：威胁人物目标 → 强：威胁生存/身份/关系根基。
- 长篇交替使用，避免章章同质「更大反派出现」。

## 写前自检（内心核对，勿单独交作业）

- 章尾具体落点是什么，读者会期待什么
- 是否真改写期待（非装饰性停顿）
- 留给下章的未决问题是否可在后续兑现

## 禁忌

- 假钩子：下章立刻无关或纯搞笑消解。
- 剧透终局；或钩子依赖读者未知的百科设定。
- 开篇加压后大段降温至无聊铺垫。
- 单独输出钩子规划稿代替正文。
