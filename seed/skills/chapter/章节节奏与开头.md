# 章节节奏与开头

每一章是完整叙事单元；开篇决定去留，读完须有净变化。章尾钩子见《章首钩子》。

## 核心原则

1. 开篇不劝退：前几段须有即时张力、推动事件或情感冲击。
2. 章内张力有升有落；读完净变化（关系/信息/局势至少一项）能一句话说清。
3. 主角用选择推动局面，而非纯旁观。
4. 若系统注入 `chapterWordTarget`，正文须落在区间内；**达标不等于不注水**。

## 读者验收五问（写前自检，勿单独输出规划稿）

1. 开篇会不会让我想划走？
2. 读完我能一句话说清「得到了什么」吗？
3. 有没有哪段像说明书/复读/注水？
4. 对白是否像不同的人在说话，且全是 “”？
5. 章末我是否想立刻看下一章（真期待，非假钩）？

## 强力开头（优先 5 类）

1. **行动中开场**：冲突高潮点切入。
2. **反常情境**：不合常理，逼问怎么回事。
3. **震撼对话**：一句改变关系/局势的话（对白用 “”）。
4. **倒计时**：明确时限与后果。
5. **重大发现**：线索/真相改变理解。

## 承上（禁复述）

- 用回声细节、未完成动作续写、物件/伤势状态承接上章。
- 禁止「上回说到」式复盘；读者已知信息不重复讲解。

## 开头禁忌

| 类型 | 为何致命 |
|------|----------|
| 天气/起床流水账 | 无冲突，劝退 |
| 「上回说到」复述 | 浪费篇幅 |
| 大段世界观倾倒 | 无行动 |
| 无意义寒暄 | 无信息 |

## 章内节奏

- 开场加压 → 中段升级或误判 → 高潮兑现/反转 → 章末牵引。
- 每场戏至少推进：情节 / 人物 / 信息 之一。
- 打破预期：读者以为会 A 时给代价更高的 B。
- 单章场景宜紧凑（通常 1–3 场），避免无信息切场。

## 写前自检（内心核对，勿单独交作业）

- 开头是否不劝退、落在哪一类手段上
- 本章必须事件是否可兑现
- 一句话净变化是什么
- 章末翻页欲是否成立（钩子细则见《章首钩子》）

## 禁忌

- 全章解释、回顾、重复无新信息。
- 高潮在开场后一路泄气至章末。
- 主角全程被推着走，无主动选择。
- 单独输出规划稿代替正文。
