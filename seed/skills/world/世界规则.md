# 世界规则

规则约束行动与冲突，不是百科背景板。读者向：规则能约束行动，非百科。

## 核心原则

1. 每条规则回答：能做什么 / 不能做什么 / 违反代价。
2. 写清信息公开度：读者 / 主角 / 配角 / 反派各知道什么。
3. 禁止临时新增万能规则救场。
4. 影响多章的规则挂到相关 **world 节点** 的 detail（如 `culture`/`history`/`factions`/`geography`），必要时补 `worldTimeline`。

## 可执行清单

1. **来源**：自然法则、制度、神明、系统、宗门、国家、副本等。
2. **边界**：允许、禁止、灰区；违反后立即代价与长期后果。
3. **反制**：能否绕开、利用、误读、升级。
4. **长期影响**：如何改变势力、地图、人物目标、伏笔。
5. **使用边界**：哪些问题不能靠本规则临时解决。
6. 影响多章的规则须可在世界节点中检索到，勿只存在于聊天记录。

## 写入自检

- 规则能否落到具体 world 节点 detail（或明确「全书元规则」写在概述/主世界节点）
- 与 level 体系、金手指边界是否打架

## 禁忌

- 只写地理风俗，无行动约束。
- 本章首次出现且正好解决死局的「新规则」。
- 规则与已有力量/势力设定互相打架且不标注。
