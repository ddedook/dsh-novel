# 物品档案要素

关键道具/神器/信物等写入 `item` 域，勿只写在正文。读者向：出场有辨识与代价，归属不乱。

## 写库要点

1. **名称唯一**：全书物品名唯一；别名可写在档案字段。
2. **主人可选**：有主则 **`owner` 传人物名字符串**（勿传 UUID）；无主/遗失/封印可空，但须在档案或 timeline 说清状态。
3. **档案写满**：按模板 key 写品级、功能、来历、限制、外观等，避免只剩名字。
4. **时间线**：认主、转手、损毁、封印、觉醒等写进 `itemTimeline`（须 `itemId|itemName` + `timeLabel` + 整数 `timePoint` + 非空 `content`）。
5. **与生物/人物分域**：活物通灵走 `creature`；人物关系走 `roleRelation`，勿塞进 item profile。

写作时突出「能解决什么 / 不能解决什么 / 暴露代价」，禁止说明书式堆设定。
