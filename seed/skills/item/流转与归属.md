# 流转与归属

物品归属变化必须同步档案与时间线，防止下一章出戏。

## 核心原则

1. 正文出现新关键物（推动冲突或爽点的道具）→ 须有 `item` 档案。
2. 获得 / 转手 / 损毁 / 认主 / 封印 → 更新 `owner`（人物名或清空）+ 写 `itemTimeline`，缺一不可。
3. `owner` = 归属主人的人物名；附属时间线宿主用 `itemName`/`itemId`，不是 owner 字段。

## 可执行清单

- 易主：旧主人失物原因 + 新主人如何得到，写进 timeline content。
- 损毁/失效：档案状态更新 + timeline 记后果（战力/关系/线索是否断裂）。
- 仅出场未易主：可只补档案；无设定变更时章节 manifest 可 `noSettingChanges`。
- 批量：先确认相关人物存在，再写 item。

## 禁忌

- 正文神器满天飞却无 item 记录。
- 只改 `owner` 不写 timeline，或只写 timeline 不改归属。
- 把生物、势力当成 item 创建。
